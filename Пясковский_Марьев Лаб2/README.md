# ЛР №2. Анализ данных. Построение инфологической модели данных БД

**Дисциплина:** Проектирование и реализация баз данных
**Вариант:** «Управление объектами жилищно-коммунального хозяйства»
**Выполнили:** Пясковский А.М., Марьёв Е.А. (группа К3240)
**Преподаватель:** Говорова М.М.

## Содержимое

| Файл | Описание |
|---|---|
| `ЛР2_ЖКХ_отчёт.docx` | Отчёт по лабораторной работе |
| `ЖКХ_Чен-Кириллов.drawio`| Инфологическая модель в нотации Чена – Кириллова |
| `ЖКХ_IDEF1X.drawio`| Модель в нотации IDEF1X |

## Кратко о модели

- Нотация Чена – Кириллова: 30 сущностей (17 стержневых, 3 характеристических, 9 ассоциативных, 1 обозначающая), атрибуты показаны овалами.
- Нотация IDEF1X: 34 сущности (4 выделены из многозначных атрибутов), 53 связи.
- Изменяемые во времени сведения хранятся с периодами действия (дата_с – дата_по); вычисляемые показатели (задолженность, остатки, расход, просрочки) не хранятся.
- Редактируемые схемы открываются в [draw.io](https://app.diagrams.net).
