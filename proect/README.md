## 1. Тема проекта

Разработка АИС подбора рецептов блюд на основе выбранных пользователем продуктов с использованием нейросети.

**Название фирмы:** CookIt

---

## 2. Назначение ИС

Информационная система предназначена для помощи пользователю в подборе рецептов блюд на основе списка имеющихся у него продуктов. Подбор осуществляется с помощью нейросети, которая анализирует введённые продукты и предлагает возможные варианты блюд.

---

## 3. Предметная область

Кулинария и домашнее приготовление пищи. Пользователь сталкивается с проблемой: «Что приготовить из того, что есть дома?». Существующие решения (сайты с рецептами) требуют ручного поиска и не учитывают конкретный набор продуктов. Предлагаемая система автоматизирует этот процесс.

**Ссылки на описание предметной области:**
- [Репозиторий проекта](https://github.com/swasty2000/CookIt.git)
- [Конкурент с похожим продуктом — DishGen](https://www.dishgen.com/)

---

## 4. Основной процесс

Подбор рецепта блюда на основе списка продуктов пользователя.

---

## 5. Внешние сущности

| Внешняя сущность | Роль |
|---|---|
| Пользователь | Регистрируется, вводит список продуктов, получает рецепт |
| Нейросеть (внешний сервис) | Принимает список продуктов, возвращает варианты блюд |

---

## 6. Накопители данных (БД)

| Накопитель | Содержимое |
|---|---|
| БД пользователей | Логин, пароль, контактные данные |
| БД истории запросов | Что вводил пользователь, какие рецепты получил |

---

## 7. Основные события (функции/процессы)

| № | Событие | Вход | Выход | Внешняя сущность |
|---|---|---|---|---|
| 1 | Зарегистрировать/авторизовать | Логин, пароль | Подтверждение | Пользователь |
| 2 | Принять список продуктов | Список продуктов | Нормализованный список | Пользователь |
| 3 | Обратиться к нейросети | Нормализованный список | Список блюд | Нейросеть |
| 4 | Сформировать рецепт | Список блюд | Рецепт | Пользователь |
| 5 | Сохранить историю | Данные запроса | Запись истории | — |
