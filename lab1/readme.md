## Задание

Разработка АИС для системы учёта личных расходов и анализа ценовых предложений LifePilot. В работе выполнен первый этап проектирования — анализ функционального поведения системы с использованием диаграмм потоков данных (DFD).

**Методология:** структурный анализ, нотация DFD Гейна–Сарсона  
**CASE-средство:** draw.io

## Описание предметной области

**LifePilot** — локальное приложение для частного пользователя, которое помогает вести историю личных покупок, сохранять наблюдения за ценами на товары и сравнивать обычные цены с рекламными предложениями.

**Пользователь:** один — владелец личного приложения. Сам вносит данные, сам принимает решения о покупках.

**Проблемы без системы:**
- данные о тратах и ценах разбросаны;
- нет единой истории цен на товар;
- сложно понять, выгодна ли акция;
- сложно быстро посчитать расходы за период;
- нет удобного сравнения цен по магазинам.

**Ограничения первой версии:**
- локальный запуск;
- один пользователь;
- нет автоматического сбора цен;
- нет интеграции с банками и платёжными системами;
- PostgreSQL как отдельная СУБД.

## Основные процессы

| № | Процесс | Назначение |
|---|---|---|
| 1 | Вести товары и магазины | Справочная информация о товарах и магазинах |
| 2 | Вести цены | История цен, сравнение, мин/макс/средняя |
| 3 | Вести рекламные предложения | Акции и сопоставление с обычными ценами |
| 4 | Вести личные покупки | Фиксация покупок, подсчёт расходов за период |
| 5 | Анализировать данные и формировать отчёты | Сводки по ценам, акциям, расходам |
