# ЛР №1. Анализ поведения системы (DFD)

**Дисциплина:** Проектирование и реализация баз данных  
**Вариант 10:** Система управления бюджетом и разделением чеков  
**Команда:** Ададурова Александра Ильинична (К3239), Поплавский Александр Леонидович (К3240), Лаврецкая Елизавета Романовна (К3240)

**Преподаватель:** Говорова Марина Михайловна  

## Тема

Проектирование информационной системы для управления бюджетом и автоматизации разделения чеков между пользователями с использованием диаграмм потоков данных (DFD).

**Методология:** структурный анализ, нотация DFD, составление матрицы списка событий,
иерархическая декомпозиция процессов  
**CASE-средство:** Ramus
